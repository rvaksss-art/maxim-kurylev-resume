# Maxim Kurylev — Product & Systems

Профессиональное CV: Lead Business Analyst / Product Owner / AI Product Builder.

Сайт: https://rvaksss-art.github.io/maxim-kurylev-resume/

## Структура

- `index.html` — основной файл для визуального редактирования; содержит стили, RU/EN-данные, JavaScript и готовую русскую разметку.
- `style.css`, `content.js`, `content.json`, `app.js` — синхронизированные отдельные версии тех же блоков.
- `assets/` — портрет, favicon и исходные PDF. PDF сохранены без редактирования и могут отличаться формулировками от сайта.
- `sync-from-index.ps1` — перенос правок HTML в данные и отдельные файлы.

## Редактирование

После изменения `index.html` выполните в PowerShell:

```powershell
.\sync-from-index.ps1
```

Скрипт читает русские текстовые поля, опыт, результаты, компетенции, проекты и ссылки, этапы работы, образование и навигацию. Английский перевод обновляется отдельно в `window.CONTENT.en`. Не запускайте `-Bootstrap` после визуального редактирования. `-Materialize` предназначен для первичного заполнения пустых контейнеров.

Обычный запуск: откройте `index.html` в браузере. Для проверки копирования email используйте HTTPS или локальный HTTP-сервер. Сборка и npm не нужны.

## Возможности и проверки

RU/EN, тёмная и светлая темы с сохранением выбора, мобильное меню, раскрываемый опыт, скачивание PDF, копирование email, reduced motion. Запуск приложения отложен до DOMContentLoaded. Русский контент доступен без JavaScript.

Проверено в Chromium/Edge: запуск без ошибок приложения, RU/EN и PDF-ссылки, сохранение темы и языка, опыт и мобильная навигация, якоря и наличие ресурсов, отсутствие горизонтального переполнения при ширинах 360, 390, 768, 1024 и 1440 px. Просмотрены снимки desktop/mobile. Это браузерная проверка, не тест на физических устройствах.
